# India, measured (demonstration build)

Built pages for a demonstration of "India, measured", a site that tracks India's economy from
official sources. Live at https://dsk180904.github.io/india-measured/

This repository holds only the generated site. Accounts, API keys, alerts and payments are
switched off in this copy. Figures belong to their publishers (World Bank, IMF, MoSPI, Reserve
Bank of India, Grid-India, PPAC, OECD, BIS, Maddison Project); credit them when reusing.
